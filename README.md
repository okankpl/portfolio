# Okan Kaplan – Portfolio

Persönliches Portfolio mit Angular, TypeScript und SCSS. Projekte und Inhalte sind auf Deutsch und Englisch verfügbar.

```sh
npm ci
npm start
```

Anschließend `http://localhost:4200/` öffnen. Unter Windows PowerShell bei Bedarf `npm.cmd` verwenden.

Die [Projektanleitung](docs/portfolio-update.md) beschreibt Projektpflege, Tests, PHP-Hosting und die Sicherung des ursprünglichen Zustands.
